## About

I'm a **software engineer and open-source contributor** working across **full-stack engineering, AI/ML, and cloud systems**. My experience includes building production-oriented applications, designing maintainable software systems, and contributing to established open-source projects, including **Apache Iceberg (PyIceberg) and Kornia**.

My research interests focus on **geometric computer vision**, particularly **Visual SLAM, 3D perception, and reconstruction**. I'm developing my research capabilities through open-source implementation and reproducible experimentation, with an interest in benchmarking, evaluation, and bridging **research methods with real-world engineering**.
